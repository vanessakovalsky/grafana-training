# Ateliers de la formation

Énoncés des exercices, annexes, environnement et fichiers d'ateliers de la formation Grafana.

| Dossier | Contenu |
|---|---|
| `exercices/` | Énoncés des labs, un fichier par module |
| `corrections/` | Corrections publiées au fil de la formation (3 à ce jour) |
| `annexes/` | Aide-mémoire, glossaire, ressources |
| `stack/` | Environnement Docker Compose de la formation (`setup.sh`, `preflight.sh`) |
| `ateliers/` | Fichiers fournis pour les labs (schéma Flow, squelette de plugin) |
| `setup-environnement.md` | Préparation du poste de travail |
